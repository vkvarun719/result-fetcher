Google Sheets Setup Guide

1 Create a Google Cloud Service Account

  1. Go to console.cloud.google.com
  2. Create a new project (e.g. "VTU Results")
  3. Enable Google Sheets API in APIs & Services → Library
  4. Go to APIs & Services → Credentials → Create Credentials → Service Account
  5. Name it anything, click Done
  6. Click the service account → Keys → Add Key → JSON
  7. Download the JSON file → rename it to google_credentials.json
  8. Place it in the same folder as server.js

2 Share your Google Sheet

  1. Open Google Sheets → Create a new spreadsheet
  2. Copy the Sheet ID from the URL:
    https://docs.google.com/spreadsheets/d/THIS_IS_YOUR_SHEET_ID/edit
  3. Click Share → paste the service account email (from the JSON, key: client_email) → give Editor access

3 Test your setup

📝 Data written to Google Sheets includes: USN, Student Name, Semester, Overall Result, and for each subject: Code, Name, Internal, External, Total, Pass/Fail.
